Fechamento de posições — casamento FIFO no grid
O bot registra fills mas nunca emite position_closed — por isso P&L, win rate e total_trades ficam em "Sem dados". Este handoff especifica o casamento compra×venda (FIFO com netting parcial): uma venda do grid fecha a compra aberta mais antiga, realiza P&L e alimenta as métricas. Design validado contra o código real.
